# CTJR_OSv3

My personal portfolio, built as a retro operating system (with an easter egg for gamers).

**Live:** https://web-portfolio-v3.vercel.app

## What it is

On desktop, the site is a retro desktop with icons, draggable windows and a taskbar. On mobile, it turns into a phone-style home screen with full-screen apps.

Open the apps to see who I am, what I've built and where I've worked:

- **About:** who I am and what I do
- **Projects:** things I've built, with details on each (to update)
- **History:** work and education timeline
- **Toolkit:** languages, tools and skills
- **GitHub:** live stats from my profile
- **Now:** what I'm working on right now
- **Contact:** how to reach me

## Highlights

- BIOS-style boot screen and CRT power-on effect
- Working Start menu, taskbar, clock and reboot
- Custom pixel cursor and a blue-screen 404 page
- A hidden easter egg. See if you can find it.

## Built with

Next.js, React, Tailwind CSS and Framer Motion.
